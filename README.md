# Lintang

Weton Jawa, Shio, Numerologi, Tarot & Astrologi dalam satu aplikasi desktop (Windows).

## Unduh

Ambil `Lintang-Setup-x.y.z.exe` terbaru di halaman [Releases](../../releases/latest), lalu jalankan.
Windows mungkin menampilkan "Windows protected your PC" karena installer belum ditandatangani: klik **More info → Run anyway**.

Lintang memperbarui dirinya sendiri secara otomatis saat ada versi baru.

## Pengembangan

```bash
npm install
npm start          # jalankan dari sumber
npm run dist       # buat installer di folder dist/
npm run release    # buat installer & terbitkan ke GitHub Releases (butuh GH_TOKEN)
```

Untuk refleksi dan hiburan.
